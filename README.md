# Capital Cities Knowledge Game
Built an interactive Python capital cities quiz with six rounds, dynamic question generation, scoring, and high-score tracking. Applied functions, loops, lists, conditional logic, and modular design to create a structured, user-friendly application.

An interactive command-line Python application that tests users' knowledge of world capital cities through a six-round multiple-choice quiz.

The game generates questions by selecting countries and providing multiple capital city options, allowing players up to three attempts per question. A scoring system awards points based on the number of attempts required, and the player's final score is compared against a stored high-score leaderboard.

# Features :
Six-round capital cities quiz with multiple-choice questions
Three attempts per question with dynamic scoring
Score calculation and high-score tracking
User input handling and answer validation
Structured program flow using modular functions
